# ふせじ

AI に渡す前に、文章・PDF・Word の中の名前や番号を記号（`[[PERSON_ID:…]]` など）に置き換え、AI の返事を元の名前に戻すブラウザアプリ。
子ども・福祉に限らず、どんな文章にも使う。
箱舟の伏せ字処理（`箱舟/lib/anonymizer.ts`）を切り出したもの。`src/anonymizer.ts` はその写しなので、直すときは両方そろえる。

## かくすもの
- 登録したもの（人の名前・あだ名／施設・会社・学校など／地域・場所／その他の言葉）。登録はチェックを通ったものだけ（`checkTerm`）
- 登録しなくても：生年月日（「生年月日：」「…生まれ」の形）、住所・住んでいる地域・駅・「〇〇在住/出身」、電話・メール・郵便番号・長い番号、施設名や「〇〇先生」、「〇〇さん」「氏名：〇〇」

## 大事な決まり
- 処理はすべてブラウザの中。サーバーへ送る処理は作らない（CSP で通信先を自分のサイトだけに制限している：`vite.config.ts`）
- 対応表（記号 → 元の名前）は画面のメモリだけ。保存しない
- 登録した名前は「覚えておく」を選んだときだけ、その端末の localStorage に残る
- 一度開けばネットなしで動く（PWA。PDF 用の日本語の対応表 `cmaps` も同梱）

## 動かし方
```
npm install
npm test             # 伏せ字のテスト
npm run dev          # 開発用
npm run serve:built  # 出来上がりを http://localhost:4174 で確かめる（ネットなし動作もこちらで確認）
```
`npm run build` でできる `dist/` を、そのまま静的サイトとして公開できる。

## 公開
`main` に push すると、GitHub Actions（`.github/workflows/pages.yml`）がテスト → ビルド → GitHub Pages への公開まで行う。
